# ADR NNNN: <the choice, phrased as the decision made>

## Status

Accepted / Superseded by ADR NNNN / Deprecated. A decision still being argued
is an [RFC](../rfcs/), not an ADR. One decision per file; when a later
decision reverses this one, mark this file Superseded and link forward rather
than editing the history out of it.

## Context

The constraint that forced a choice, the alternatives seriously considered,
and why the status quo did not hold. A reader two years from now must be able
to tell whether the constraint is still true without reading the whole tree.
Where the constraint is measured (popularity, cost, version), name the
artifact or tool that measured it and when.

## Decision

The choice, in one or two sentences. Not the implementation: that lives in the
code and, where the decision is part of a larger capability, in a
[PRD](../prds/).

## Consequences

What this makes easy, what it forecloses, and the honest downside. Name the
gate this decision protects or weakens and what evidence would justify
revisiting it.
